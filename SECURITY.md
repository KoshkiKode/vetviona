# Security Policy

## Supported Versions

Security fixes are provided for the latest released 1.x version of Vetviona.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Please **do not** open a public issue for a security problem.

Report it privately with GitHub's **Security → Report a vulnerability** button
(private vulnerability reporting is enabled for this repository). Include the
affected version, steps to reproduce, and the impact you expect. We will
acknowledge the report and keep you informed until it is resolved.
